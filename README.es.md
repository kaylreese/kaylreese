# ¡Hola, soy Samuel Bocanegra! 👋
Soy profesional de Ingeniería de Sistemas e Informática, con más de 5 años de experiencia en desarrollo de software, administración de bases de datos e infraestructura tecnológica.

Mi experiencia abarca el desarrollo full-stack y backend con JavaScript, TypeScript, React, Node.js, Next.js, PHP, Laravel, CodeIgniter, Python y FastAPI. También tengo experiencia administrando bases de datos relacionales y NoSQL, como Oracle Database, PostgreSQL, MySQL, SQL Server, MariaDB y MongoDB.

Trabajo con tecnologías de contenedorización, despliegue y procesamiento de eventos, como Docker, Kubernetes, Apache Kafka y Redpanda. También desarrollo soluciones backend con SQLAlchemy y Go utilizando Fiber.

Me apasiona diseñar arquitecturas escalables, automatizar procesos y construir soluciones tecnológicas que resuelvan problemas reales, combinando ingeniería de software, gestión de datos e infraestructura.

## 🚀 Proyectos destacados
### 🏢 BIJAO — Sistema Integrado de Gestión de Infraestructura Tecnológica
Plataforma diseñada para centralizar la gestión de activos tecnológicos e infraestructura empresarial. Incluye inventario de servidores, bases de datos, direcciones IP, redes y componentes de infraestructura, además de monitoreo, visualización de topología de red, control de accesos e integración con iTop.

**Tecnologías:** FastAPI, Python, Next.js, React, TypeScript, Oracle Database, SQLAlchemy y Docker.

### ☁️ Kore — Plataforma de Gestión de Servidores y Despliegues
Plataforma ligera y autohospedada para administrar servidores, desplegar aplicaciones y automatizar procesos DevOps. Diseñada para funcionar eficientemente en servidores con recursos limitados, centraliza la gestión de infraestructura, CI/CD, monitoreo, redes y seguridad en una sola interfaz.

**Tecnologías:** Go, Fiber v3, Next.js, TypeScript, PostgreSQL, Docker y Traefik.

### 🧾 CloudFact — Plataforma SaaS de Facturación Electrónica
Plataforma SaaS de facturación electrónica orientada al mercado peruano, dirigida a restaurantes, sistemas de punto de venta (POS), comercio electrónico y aplicaciones empresariales. Ofrece integración mediante API REST y automatiza la emisión, el envío y el seguimiento de facturas y boletas electrónicas ante SUNAT.

Su arquitectura multitenant admite modelos de base de datos Freemium, compartido y aislado, con estrategias de aislamiento de datos, administración de conexiones y mecanismos de escalabilidad para optimizar el uso de recursos según la demanda.

CloudFact integra **Nimbus**, un componente propio desarrollado en Go para la orquestación de procesos y la ejecución resiliente de operaciones de facturación. También incorpora una biblioteca propia de carrito de compras para integrarse con los flujos de comercio electrónico.

La plataforma cuenta con observabilidad mediante Prometheus, Grafana y Jaeger para la recopilación de métricas, la visualización del rendimiento y el rastreo distribuido.

**Tecnologías:** Python, FastAPI, Next.js, TypeScript, PostgreSQL, SQLAlchemy, Redis, Docker, Prometheus, Grafana, Jaeger y Go.

**Enfoque técnico:** arquitectura SaaS multitenant, facturación electrónica, procesamiento asíncrono, observabilidad, integración de sistemas, gestión de recursos de bases de datos y componentes de software reutilizables.

### 🤝 HubService — Plataforma B2B de Servicios Tecnológicos
Plataforma B2B que conecta especialistas tecnológicos con empresas para facilitar la contratación y gestión de servicios profesionales. Incluye chat en tiempo real, sesiones de soporte por horas y un temporizador automático que se pausa cuando se cierra la ventana de soporte, facilitando el seguimiento del tiempo dedicado a cada servicio.

Integra Microsoft Teams para la colaboración empresarial e incorpora gestión de contratos, seguimiento de servicios y evidencias. Utiliza Redpanda para la mensajería y el procesamiento asíncrono de eventos, junto con **Nimbus**, un componente propio desarrollado en Go para la orquestación de procesos y la automatización.

**Tecnologías:** Next.js, TypeScript, FastAPI, Redpanda, Go, Fiber, Docker, Microsoft Teams, Culqi y Stripe.

**Enfoque técnico:** arquitectura orientada a eventos, comunicación en tiempo real, gestión de sesiones, control de horas facturables, integraciones empresariales y automatización.
